3. 1-CLICK EASY INSTALLATION VIA WORDPRESS:
========================================================================

STEP 1: UPLOAD & ACTIVATE THEME
1. WP Admin -> "Appearance" -> "Themes".
2. Click "Add New Theme" -> "Upload Theme".
3. Upload "rakta-infotech.zip" and click "Activate".

STEP 2: 1-CLICK INSTALL ALL PLUGINS (TGMPA)
1. Theme activate hote hi WordPress ke upar ek bar aayegi:
   "Rakta Infotech Theme requires/recommends the following plugins..."
2. Click "Begin installing plugins" -> Select All -> Choose "Install" -> Click "Apply".
3. Click "Begin activating plugins" -> Select All -> Choose "Activate" -> Click "Apply".
   (Aap "Appearance" -> "3D Theme Setup" se bhi live status dekh sakte hain!)

STEP 3: 1-CLICK AUTO 3D PAGES SETUP
1. WP Admin -> "Appearance" -> "3D Theme Setup".
2. Click "⚡ 1-Click Auto Setup All 3D Pages".
3. Done! Saare 6 pages live ho jayenge with full 3D interactive graphics!

========================================================================
4. HOW TO EDIT IN ELEMENTOR:
========================================================================
1. Go to "Pages" -> "All Pages".
2. Hover over Home / About / Services / Portfolio / Contact.
3. Click "Edit with Elementor".
4. Saara 3D visual content canvas par pehle se loaded hai - text ya images 
   par click karke customize karein!
